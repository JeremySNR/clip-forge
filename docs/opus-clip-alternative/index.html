Cutawan / Opus Clip alternative

YOUR WORKFLOW, YOUR CALL.

An open-source Opus Clip alternative.
On your desktop.

If you want to turn long videos into short clips while keeping control of the editor, the source code and your local files, Cutawan is built for that.

The short version: Cutawan is a free desktop app for Windows, macOS and Linux. It combines AI highlight discovery, animated captions, speaker-aware reframing and local MP4 export. The default setup uses your own OpenAI API key, with usage billed separately.

What you get with Cutawan

A good fit if you want…

  • A desktop workflow. Work with local source footage and export video files directly on your own computer.
  • AI assistance with the final say. Use suggested moments as a starting point, then review the context, captions and cut yourself.
  • More control over the tool. Run the source, inspect the implementation and customise it under the MIT licence.
  • A whole-video captioning mode. You can caption and reframe an entire video without asking AI to find highlights.

Know the tradeoffs before switching

Cutawan requires a desktop installation and some initial AI-provider setup. Processing speed depends on your computer. It does not currently offer automatic publishing to your social accounts: you export a file and upload it yourself.

It is also not fully offline by default. With the standard OpenAI setup, extracted audio, transcripts and sampled frames are sent for AI processing. The original video, editing, speaker tracking, rendering and export stay local.

If your priority is a managed browser workflow, shared cloud projects or automatic publishing, evaluate those requirements carefully. This guide describes Cutawan’s capabilities; it does not assume another product’s current prices or plan limits.

Is it completely free to use?

The software is free, including exports without a forced watermark. API costs are separate and depend on your provider, model, video length and enabled analysis. A ChatGPT subscription does not include OpenAI API credits. Review your provider’s pricing and usage limits before processing a large library.

Try it with one video

Start with a podcast, interview or recording you own. Review the suggested clips, open one in the editor, adjust its captions and framing, then export it. That is a useful way to judge whether the workflow suits you.
